# 🎓 Student Expense Tracker

A modern, responsive, student-friendly Expense & Budget Tracking web application.

---

## 🚀 Features
- **Budget Tracking**: Set a monthly budget, monitor spending, and view remaining balance in real time.
- **Budget Alerts**: Visual warning system when you reach 80% or exceed 100% of your budget.
- **Categorization**: Food, Books & Study, Rent, Commute, Entertainment, and Others.
- **Category Filter**: Filter expenses by category to see where money goes.
- **Offline & Persistent**: Automatically saves all your data in browser `localStorage`.
- **CSV Export**: One-click download of all records into an Excel/Google Sheets-compatible `.csv` file.
- **Dark / Light Theme**: Toggle between eye-friendly dark mode and crisp light mode.
